# Last updated: 2026-06-07 | Version: 0.2

=== Architecture ===
Music Copilot is a desktop app (Electron + React + FastAPI + SQLite) for FL Studio producers.
All AI goes through providers.generate(prompt) — never direct API calls.
All features are plugins under plugins/ — every Plugin ABC subclass is auto-discovered.
Plugins communicate via event_bus.emit() — never call another plugin directly.
Audio/MIDI analysis is fully offline (librosa, deeprhythm, music21).
LLMs never touch raw audio — audio goes through DSP first, then structured JSON is sent.

=== Available Plugins ===
sample_analyzer — BPM (deeprhythm), key/scale (music21 Krumhansl-Schmuckler), spectral features
theory_engine — scales, chords, intervals, functions (deterministic, no AI)
chord_generator — 7 moods, 24 keys, 9 chord qualities, voice-leading scoring via music21
melody_generator — isobar-based, genre-aware, phrase arc velocity, articulation gate
bassline_generator — 4 patterns per genre, trance octave jumps
midi_export — swing quantization, velocity arcs, articulation, multiple voicings

=== Configuration ===
Project: {name, bpm, key, scale} — editable via inline hover edit
Generate panel: {key, scale, mood, genre, length, complexity, pattern}
MIDI Player: per-part mute, swing slider (0-100%), history cycling, regenerate/clear
Generation Hub: full controls, NoteGrid preview, Play/Stop, MIDI export, Save to Library

=== Providers (AI) ===
groq — default, llama-3.3-70b-versatile, httpx POST to api.groq.com
openrouter — fallback, supports many models via single API key
openai — stub (not implemented)
glm — stub (not implemented)
Auto-failover: on 429 rate limit, tries next provider in priority order

=== Music Theory Constants ===
12 semitones: C=0, C#=1, D=2, D#=3, E=4, F=5, F#=6, G=7, G#=8, A=9, A#=10, B=11
Chord intervals (semitones from root):
  major=[0,4,7] minor=[0,3,7] dim=[0,3,6] aug=[0,4,8]
  maj7=[0,4,7,11] min7=[0,3,7,10] dom7=[0,4,7,10] sus2=[0,2,7] sus4=[0,5,7]
Diatonic qualities (major): [major, minor, minor, major, major, minor, diminished]
Diatonic qualities (minor): [minor, diminished, major, minor, minor, major, major]

=== FL Studio Workflow ===
MIDI Export: Click "Export MIDI" in MIDI Player or Generation Hub → downloads .mid file.
  Drag the .mid file from your downloads folder into FL Studio's Channel Rack or Piano Roll.
  Each part (chords/melody/bassline) exports as a separate track in the MIDI file.
Matching Tempo: Set your project BPM in Music Copilot's Project panel to match FL Studio.
  The generated MIDI will align perfectly when you drag it in.
Using Generated Content:
  Chords → Piano Roll (layer multiple chord notes per beat).
  Melody → Channel Rack (assign to a synth like Sytrus, Harmor, or Serum).
  Bassline → Channel Rack (assign to a sub-bass patch or 808).
Swing: Use the swing slider (0-100%) to add groove before exporting.
  House/DnB: 20-40%. Techno: 0-10%. Deep House: 30-50%.

=== Genre Production Tips ===
House (Deep / Progressive):
  Use 4-on-the-floor kick, offbeat hi-hats, clap on 2 and 4.
  Chords: I-IV-V-I or vi-IV-I-V, 7th chords for lushness.
  Bass: Root notes on beats 1 and 3, syncopation between.
Techno:
  Kick on every beat, hi-hats with shuffle, minimal percussion.
  Chords: Minor vamps (i-iv-vII-i), dark ambience between hits.
  Bass: Low-pass filtered, root-fifth pattern with distortion.
Trance:
  Kick on 1, rolling hi-hats (16th notes), snare/clap on 2 and 4.
  Chords: Arpeggiated majestic progressions (I-V-vi-IV).
  Bass: Octave-jumping root-fifth pattern, side-chained to kick.
Drum & Bass:
  Kick on 1, snare on 3 (half-time feel), fast hi-hats (32nd notes).
  Chords: Minor and diminished, atmospheric pads.
  Bass: Heavy sub-bass, mid-range Reese bass with detuned saws.

=== Arrangement Structure ===
Common 128-BPM House Structure (8-bar sections):
  Intro (16 bars) — Kick, hats, atmosphere, build FX.
  Breakdown (16 bars) — Melody intro, filtered chords.
  Build (8 bars) — Rising white noise, snare roll every 2 bars.
  Drop (16 bars) — Full elements, main hook.
  Bridge (16 bars) — Filtered, fewer elements, tension release.
  Second Drop (16 bars) — Full energy, possible variation.
  Outro (16 bars) — Strip back, reverb tail, fade.
Techno Structure: 16-bar loops with subtle variations every 8 bars.
  Minimal intro (no kick) → Kick enters → Layer by layer → Drop → Strip → Rebuild.
DnB Structure: Double-time tempo (174 BPM), half-time feel.
  Intro → Atmospheric pad → Drums enter → Bass → Drop → Breakdown → Second Drop.

=== How to Use the Chat ===
Ask about music theory: intervals, chords, scales, key changes, voice leading.
Ask about arrangement: song structure, section transitions, tension building.
Ask for sound design: "How do I make a Reese bass?" or "What synth for pluck leads?"
Ask about production workflow: "How should I layer my kick and sub-bass?"
The AI CANNOT execute tools or generate MIDI from chat. Use the Generate panel for that.
The AI has no internet access — it answers from its training + this knowledge base.

=== Key Actions ===
Ctrl+K — Global search (Library, samples)
Ctrl+Enter — Auto-generate (chords → melody → bassline)
Ctrl+Shift+M — Export all MIDI
Ctrl+S — Save arrangement to Library
Enter in chat — Send message (Shift+Enter for newline)
