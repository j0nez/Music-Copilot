# Research

Individual research documents for technical decisions in Music Copilot.

## Topics

1. **[Project-Based Tool Patterns](./project-based-tools.md)** — How DAWs, creative software, and broader applications handle sessions, projects, templates, and state management.
2. **[Note & Chord Recognition](./note-chord-recognition.md)** — Monophonic and polyphonic pitch/chord detection from audio. Offline-capable approaches. *(Researched — 2026-06-05)*
3. **[FL Studio Integration & VST Plugin Development](./fl-studio-integration.md)** — FL Studio Python API, MIDI scripting, piano roll/Edison scripting, virtual MIDI ports (loopMIDI, Windows MIDI Services), Flapi remote control, JUCE-based VST3 bridge plugins, browser-to-DAW drag-and-drop, and a tiered integration architecture plan. *(Researched — 2026-06-05)*
4. **[Model Recommendations](./model-recommendations.md)** — Lightweight offline models vs. free API tiers for audio, MIDI, and music analysis. Evaluates BPM/key, stem separation, music tagging, generation, LLM inference, and structure analysis with comparison tables, phase-based recommendations, and license analysis. *(Researched — 2026-06-05)*
5. **[Music Theory & Music Algorithms](./music-theory-algorithms.md)** — Counterpoint, voice-leading, cadence detection, key modulation, and algorithmic composition. *(Researched — 2026-06-05)*
6. **Advanced MIDI Generation** — Multi-track MIDI, procedural melody, swing quantization, velocity patterns, and note expression. *(Not yet researched.)*
7. **Overall Musical Understanding** — Structure analysis, genre classification, harmonic reduction, and intelligent music comprehension. *(Not yet researched.)*
